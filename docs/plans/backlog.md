# Backlog

Two kinds of item live here. **Ideas** are potential enhancements that are not in the [PRD](../spec/prd.md) or any plan yet: each says where it came from, what it would change, roughly what it costs, and what would make it worth doing; one leaves when it is adopted into the PRD (noted in the PRD's "What changed") or declined, in which case it moves to [Declined](#declined) with the reason. **Adopted requirements not yet built** are PRD requirements and spec sections (Draft 1.4) that the code does not implement yet; each row is a brief another agent can start from, and leaves when built and its beads issue is closed. Spec §16 gives their order (H1–H5), repeated under [Order of work](#order-of-work). The [plans index](README.md) explains how this fits the other documents.

Status is tracked in beads (`bd`): one issue per row, backlinked here; ideas are `deferred` with the `idea` label. Items are grouped by the area they touch, not by priority; for ideas the **Worth it when** column is the trigger to pick one up.
